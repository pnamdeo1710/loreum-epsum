## What this repo is

**loreum-epsum** is a sanctuary for placeholder text — the quiet scaffolding
that holds up every unfinished design on Earth. Treat the misspelling as
canonical: it is *loreum*, it is *epsum*, and we do not apologize to spell-check.

## Prime directives for Claude

- **Honor the nonsense.** Lorem text is a feature, not a bug. Never "fix"
  placeholder copy into real sentences unless explicitly asked.
- **Keep it readable to humans first, machines second.** If a change makes the
  repo harder to skim, reconsider it.
- **Small commits, signed.** Every commit here is GPG-signed (key `9FDA…F1AF`)
  and authored as `priyansh.namdeo.10@gmail.com`. Keep it that way.
- **When in doubt, add whimsy, not complexity.**
